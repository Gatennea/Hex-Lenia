# 方格核 vs 六角核：原版生物对照实验

> 工具：`node compare_grids.js A B`　原始数据：`data/compare_results.txt`（57 种 + 水母对照，每批重复水母）

## 方法（单变量对照）

同一套 FFT 卷积 / 增长函数 / Euler 更新引擎，**只换 `rules[0].kf`（核的格几何）**：

| 端 | 核距离 | 对应 |
|----|--------|------|
| 六角 | `dx=dq+dr/2, dy=√3/2·dr`（轴向笛卡尔） | 游戏现状 |
| 方格 | `dx=dq, dy=dr`（整数格欧氏） | 原版 Lenia 出身处 |

每种生物：清场 → 居中放置 → 各跑 **300 步**，每 20 步采样质心。

**指标**：存活（d>5e-4）｜活动度 act（末5步 mean|Δ|/N，死场恒为0）｜速度 v（质心路径/步，按各自格几何换算笛卡尔）｜直线度（净位移/路径）｜晶格偏差（航向与最近晶格轴的夹角，六角60°族/方格45°族）｜形变（质心回中后 L1）

## 结果一：存活率——每种格子都偏爱"本地物种"

| | 六角核 | 方格核 |
|---|---|---|
| 57 种原版生物 @300 步 | **40/57 (70.2%)** | **54/57 (94.7%)** |
| 水母（hex 原生对照） | 活（呼吸+飞行） | **死**（飞一段后崩解） |

- **双向本地优势**：原版生物在方格更稳（它们就是被进化到那里的）；我们的水母只活在六角。
- **六角是更严酷的环境**：17 种死在六角（其中 14 种方格安然）——全部表现为"**飞一段然后彻底崩解**"（act=0=空场）。
- **双网格都死的 3 种**：Gyropteron serratus velox [2PG1]、Octapteryx serratus cavus labens [2P8]、Nonapteryx serratus sinus labens [2P9]。
- ⚠️ **这直接修正了"57 幸存"名单**：那是 200 步筛选的上界，300 步已淘汰 17 种 → 长跑复核（2000 步）确有必要。
- 最强健：**Bug(bigger)**——双网格都活，且都是混沌高速（act≈1.2e-1，v≈1.6/2.0）。

## 结果二：行为差异（双方都活的配对）

### 1. 速度双向分化，可差一个数量级

| 生物 | 六角 | 方格 | 倍率 |
|------|-----:|-----:|-----|
| Decadentium rotans trioculi [2D10] | **1.213** | 0.092 | 13× 六角 |
| Pentapteryx cavus saliens [P5(f)] | 0.127 | **0.634** | 5× 方格 |
| Pyroscutium ambiguus serratus [2PS3] | **1.150** | 0.536 | 2.1× 六角 |
| Paraptera arcus saliens [P4(c)] | **1.014** | 0.457 | 2.2× 六角 |
| Aerogeminium volitans [2G]（方格活/六角死） | 0.428† | **1.218** | 方格占优 |
| Bug(bigger) | 1.565 | **1.996** | 1.3× 方格 |

† 六角端已濒临崩解。结论：**速度 = 结构节奏 × 晶格几何的共振**，无单向快慢偏置——换格子不是简单"变快/变慢"，而是每个结构重新洗牌。

### 2. 方格 = 滑翔道；六角 = 自由航向

saliens（跳跃）族在方格上显著**直线化 + 保形**：

| 生物 | 直线度 六角→方格 | 形变 六角→方格 |
|------|------------------|----------------|
| Paraptera arcus saliens [P4(c)] | 0.25 → **1.00** | 1.00 → **0.05** |
| Paraptera arcus pedes [P4(e)] | 0.29 → **0.99** | 1.00 → **0.06** |
| Heptascutium [S7] | 1.00 → 1.00 | 0.64 → **0.04** |
| Heptapteryx serratus liquefaciens [2P7] | 0.34 → **0.99** | — |
| Hexacaudopteryx [P6,4] | 0.98 → 1.00 | 1.00 → **0.22**（偏=1.3°！） |

- 晶格偏差：方格航向普遍贴 45° 族（6–16°，最低 1.3°），六角多在 9–30°（Octahelicium 达 30°=恰在两轴正中）→ **方格的晶格会"俘获"航向形成滑翔道；六角无 preferred direction**——与水母各向同性实验（0° 偏差）互为印证。
- labens（爬行）族两网格形变都≈1：**边飞边蜕**是族名本义（"滑行"），不受晶格影响。

### 3. 螺旋族（H 系）行为反转

| 生物 | 六角 | 方格 |
|------|------|------|
| Heptahelicium solidus [H7] | 直线飞 v=0.74 **然后死** | 原地卷曲 v=0.003 **活** |
| Nonahelicium ignis [H9] | 直线飞 v=0.45 **然后死** | 近静止 v=0.009 **活** |
| Octahelicium [H8] | 直线飞 v=0.74 **然后死** | 静止 v=0.000 **活** |

**解读**：螺旋结构的设计行为是"原地转圈"（方格上确实如此）；六角核的邻域几何干扰了螺旋自洽 → 被"甩直"起飞 → 迁移中崩解。这是**晶格几何改变结构命运**的最戏剧例证。

### 4. 水母（反向对照）

- 六角：v=0.836、呼吸 act=6.4e-4、形变0.10 —— 健康飞行。
- 方格：v=0.310、直线度0.95、**形变1.00、末态 act=0 → 崩解死亡**。
- 我们自己进化的生物是 hex-native：**水母在方格上"蜕变成别的东西然后死"**。

## 可复现性

水母在 8 个批次中重复跑了 8 次，**数字逐位一致**（act=6.4e-4 / v=0.836 / …）→ 确定性系统，结果完全可复现。

## 局限

1. 300 步窗口（长期行为需 2000 步复核，见"57 名单修正"）。
2. 方格端用**我们的核映射**（`k=bump4→exp`、`k=stpz1/4` 因正则截断落回 `exp` 等），是"近似原版核型"，非 `Lenia.html` 逐位复刻——原版引擎复跑列为后续项。
3. 形变指标对曲线路径有残余混淆（回中只消除平移）。
4. 幸存者偏差：57 种是按六角 200 步筛选的，本实验第 1 节正是在量化这个偏差。
